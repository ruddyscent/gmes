# Security policy

Security fixes are provided for the current development release only. Python 2
and the retired native solver/API are unsupported. Supported runtime reports
should identify the Python/PyTorch version and the requested device without
including credentials or private machine data.

Please report suspected vulnerabilities privately through the repository's GitHub Security Advisory interface. Do not include confidential exploit details in a public issue. General correctness bugs and numerical problems can be reported through the regular issue tracker.
